# CSS responsivo – NeoTerra

## 1. Objetivo
Estilos limpos, consistentes e mobile-first para a calculadora e páginas de contato.

## 2. Contexto do projeto
CSS3 puro sem frameworks, organizado em arquivos externos sob o diretório public/css/.

## 3. Regras detalhadas
- Utilize a abordagem mobile-first com media queries para telas maiores.
- Mantenha variáveis CSS padronizadas para cores, fontes e espaçamentos.
- Garanta consistência visual entre todas as páginas do site.

## 4. Exemplo
```css
body {
  font-family: sans-serif;
  margin: 0;
  padding: 0;
}
```
## 5.Erros a evitar
- Não utilize estilos inline nas marcações HTML.   
- Não utilize frameworks de CSS (como Bootstrap ou Tailwind).
